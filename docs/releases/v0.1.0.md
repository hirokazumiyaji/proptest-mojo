# v0.1.0

This is the first release of proptest-mojo, a Pure Mojo property-based testing library. It supports generating examples, running properties, shrinking failures, and replaying counterexamples.

## Getting started

Install [pixi](https://pixi.sh/) and clone the tagged release:

```sh
git clone --branch v0.1.0 https://github.com/hirokazumiyaji/proptest-mojo.git
cd proptest-mojo
pixi install
pixi run mojo run -I src examples/basic.mojo < /dev/null
```

Published releases also ship a conda package built for Mojo `1.1.0` and a GitHub Release. See the [setup guide](../guide/setup.md) for conda and source-checkout consumption.

## Included

- Strategies for primitive, collection, tuple, choice, and recursive values, with strategy composition.
- `for_all` and configurable settings for seeds, example counts, choice limits, shrink budgets, replay, verbosity, and database use.
- Choice-sequence shrinking with deletion, zeroing, individual minimization, and an evaluation budget.
- Failure reports with counterexamples, draw records, replay data, and seeds.
- A user guide and runnable examples.

## Limitations

Conda packages target Mojo `1.1.0`. Source checkouts should use the Mojo version pinned in the release's `pixi.lock`. GitHub Releases publish release notes from `docs/releases/` when present.
